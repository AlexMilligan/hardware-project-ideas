# Hardware project ideas

A notebook of beginner electronics projects. Alex is new to hardware, and the pages are written that way: short, in order, and honest when something has not been tried.

The write-ups live in [`src/content/docs/`](src/content/docs/) and are built with [Astro Starlight](https://starlight.astro.build/). This README is only the GitHub landing page. The site is the canonical copy, so project pages are not repeated as extra READMEs.

**Site:** https://alexmilligan.github.io/hardware-project-ideas/

## Status

Every project has a **status** (how far the plan has gone) and one or more **evidence** tags (what has actually been tried). A finished-looking write-up can still be unbuilt.

| Status | Meaning |
| --- | --- |
| idea | Not designed yet |
| draft design | A plan exists. Parts are not ordered and nothing is built |
| parts ordered | Parts are on the way or in hand. Not built |
| desk test | Something runs on the bench. Not worn or finished |
| built | Made as the page describes |
| abandoned | Stopped. The page says why |

| Evidence | Meaning |
| --- | --- |
| unbuilt | No hardware has been assembled for this project |
| hardware untested | The wiring or parts have not been checked on the bench |
| firmware untested | Code for this project has not been run on the hardware |
| verified on bench | The check named on the page was done, and it passed |

Nothing in this repo is verified on the bench yet.
